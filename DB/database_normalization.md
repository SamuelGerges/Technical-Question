## Database Normalization
    it  is a way to organize data in a database to reduce duplication (repeating data),
    and ensure data is stored in a clear and efficient way.
    it divides a large table into smaller related tables and connects them using relationships 
    
### Normalization helps:
        Reduce repeated data
        Make changes easier
        Keep data accurate and clean
### Types of Database Normalization
    - 1NF
        - Remove repeating columns and make sure each field has only one value.
    - 2NF 
        - Remove data that does not depend on the whole primary key.
    - 3NF
        - Remove data that does not depend on the key (non-key dependencies).
